# Lerntyp

Lern-App für Klassenstufe 4 in Baden-Württemberg (9–10 Jahre), die Schulklassen gemeinsam auf Tablets nutzen.

Kinder finden heraus, **wie** sie lernen – evidenzbasiert, ohne Lerntyp-Etiketten. Statt „Du bist ein visueller Typ“ gibt es ein stärkenorientiertes **Lernprofil** und das Klassenexperiment **Lerndetektive**.

Projektstatus: Konzeptphase. Die Dokumentation folgt in `docs/`.
