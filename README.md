# Lerntyp

Lerntyp ist eine Tablet-App für Klassenstufe 4 in Baden-Württemberg (9–10 Jahre), die Schulklassen gemeinsam im Unterricht nutzen. Kinder finden heraus, **wie** sie lernen: mit dem stärkenorientierten **Lernprofil** („Mein Lernprofil“ mit drei Stärken und einer Lern-Superkraft) und dem Klassenexperiment **Lerndetektive**. Lehrkräfte steuern die Stunde über das Lehrkraft-Cockpit; Kinder arbeiten mit einem Lernausweis und einem Alias, nie mit ihrem Namen.

## Warum keine Lerntypen?

Die Annahme, Kinder lernten besser, wenn der Unterricht zu ihrem „Lerntyp“ (z. B. visuell oder auditiv) passt, ist wissenschaftlich nicht belegt; Studien zur Passungshypothese (englisch- und deutschsprachig) finden keinen Lernvorteil (Dossier [§1.1](docs/research/00-dossier.md)). Solche Etiketten können Neun- bis Zehnjährige zudem auf feste Fähigkeitsvorstellungen festlegen. Deshalb gibt es bei Lerntyp keine Typen, sondern beobachtetes Verhalten, sechs trainierbare Lernstrategien und ein Experiment, das die Idee gemeinsam prüft.
